Control panel — the settings window (10 sections)

SettingsApp.tsx's navigation array is the source of truth for order/count: General, Football, News, Agents, Shortcuts, Appearance, Diagnostics, History, Queue, About — 10 sections, sidebar icon + label each, no per-row index badge (the "01"/"02"… index now only appears in the pane header, e.g. "Settings / 04"). Two sections are drawn out in full below (General and Agents); the other eight are summarized in prose with their real control list.

Tokens mirror vendor/shared-ui/design/tokens.css + src/settings/base.css: window #050607, sidebar #090a0c, surface/card #0d0f12, border/divider #202329 (also the value --input/ --accent/--secondary/--muted all share), accent/primary #0a84ff — used for the Save button fill, a checked Switch, focus rings, and the active sidebar item's tint/rail, not just one place. The type floor is four fixed sizes (9/10/11/19px, --fs-caption/secondary/body/title); nothing in this window uses a font size outside that scale except a couple of named, commented exceptions in the real CSS (e.g. the Appearance preview label's 12px).

01 — General

Four groups: Engine (start-paused/hide-when-idle/history toggles, listener port, a test-notification button), Rotation and priority (rotation seconds, queue cap per tier, manual push priority), Rotation order (a reorderable list — same-tier tie-break), and Silenced (a persisted daily buffer window, distinct from the tray's session-only Timed Mutes/Skip).

04 — Agents

The v7 Agent Adapter section (spec §4.6/§8) — the newest and largest section. Four groups: Agent Adapters (master enable + retention/stale settings), Notification priority (one Low/Medium/High segmented per event kind: permission requested, input required, failed, completed), Adapters (one card per supported runtime — enable toggle, live health, the exact setup snippet + target file to copy, a "send test event" button, uninstall instructions), and Preview (five static text rows showing what the overlay's Agent Board looks like per state — this settings window never renders the live Agent Board component itself). Only Claude Code and Codex's cards are drawn below; Kimi and OpenCode use the identical card shape with their own snippet/target file.

Sections not drawn out in full

Every other section, with its real control list and copy — same window chrome (sidebar/header/footer) as above, just not re-rendered pixel-by-pixel here.

  • 02 Football — one group ("Score polling"): a Football identity chip, enable toggle, a leagues textarea (one ESPN league code per line), poll interval, rotation seconds, a "Live match card" toggle (consolidate updates into one card instead of a burst), a "Richer match events" toggle (fouls/offsides/VAR/subs, opt-in — heavier polling), priority segmented, test button.
  • 03 News — one group ("RSS polling"): enable toggle, feeds textarea, topics textarea (searched via Google News, merged into the same stream), poll interval, headline rotation seconds, max-per-poll burst cap, priority segmented, test button, an ad-hoc "Search now" row (one-off Google News search, not saved as a topic), and a read-only category-colour legend (six chips: Politics/Tech/Sports/Business/World/Science).
  • 05 Shortcuts — one group, a real <table> of 7 active shortcut rows.
  • 06 Appearance — card shape controls and the overlay preview gallery.
  • 07 Diagnostics — a read-only log tail and a manual Refresh button.
  • 08 History — recorded notifications and a two-step Clear history button.
  • 09 Queue — waiting items, Refresh, Skip current, and Clear queue controls.
  • 10 About — identity, usage, stack, and live system information.
