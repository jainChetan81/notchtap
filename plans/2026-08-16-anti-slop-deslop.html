Appendix 1 — comment-purge execution rules
DELETE lines matching: plan \d+, ISO dates, formerly/previously/used to/no longer/now deleted/renamed/superseded/review fix/audit finding/FEEL-CHECK…HISTORY/pre-plan; and comments reconstructable from the code below. COMPRESS load-bearing blocks to ≤3 present-tense lines, preserving by name: hover.rs↔icon-strip.css / FLANK_INSET↔card-chrome.css / hovered_right_flank_width↔--cw couplings (stripGeometryParity.test.ts is the tripwire); the dedup_eq rule; "receive-only, no invoke"; poison-tolerant lock; "read ambient handles before locking the queue". KEEP VERBATIM: 38 biome-ignore (3 say "see comment above" — inline the reason), 3 @ts-expect-error, #[allow] trailing justifications, 14 rust doctest fences, ALLOWLISTED_TRANSITIONS justifications. NEVER write in a comment: tauri::generate_handler![, ]; inside doctor.rs's hook-events region, backtick-semicolon inside AgentsSection's snippet const, unbalanced braces in CSS rule bodies. Pass order: CSS → web-root → web-components → web-settings+adapters → web-tests → rust-agents → rust-core small → queue.rs, lib.rs each alone. Gate after each pass: full CI mirror + read diffs of the 10 source-parsing tests. Purity check: git diff -U0 | grep '^+' | grep -v '^+++' | grep -vE '^\+\s*(//|/\*|\*|$)' empty on deletion passes. Plan numbers inside test describe/it strings: separate later pass.
